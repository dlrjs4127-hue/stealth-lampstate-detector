# 데이터 카드 (Dataset Card)

## 1. 합성 CCTV 장면 (스텔스 차량)
- **생성 방식**: 실제 ITS 야간 CCTV 프레임을 배경으로 두고, 차량 영역만 이미지 생성 모델로 만들어 합성.
- **규모**: 합성본 58장(표적 1대 = stealth_vehicle, 주변 점등 차량 = normal_vehicle).
- **라벨**: 표적은 수동 BBOX, 주변 차량은 검출기 자동 후보(의사 라벨).
- **조도 변형**: base / dark / gamma_low / cool / warm / noisy / blur 7종 파생(406장).
- **한계**: 표적 램프 표현이 실제 소등과 완전히 같지 않고, 합성 경계가 남아 있을 수 있음.

## 2. 실제 프레임 (평가용)
- 야간 고정 CCTV 프레임 102장(고속도로·교량 등), 학습/평가를 프레임 단위로 분리.
- 소등 차량 정답 라벨은 현재 0건이라, 평가는 검출 수·화면 확인 중심.

## 3. 실제 ON/OFF 대응 크롭 (혼합 실험)
- 공개 데이터(Roboflow, CC BY 4.0)에서 수집한 차량 크롭. ON 628 / OFF 628.
- 같은 차량의 ON/OFF 대응쌍이라 "소등 판별" 신호를 학습하는 데 사용.

## 4. 권리·배포
- 원본 CCTV 프레임과 합성 이미지는 권리 확인 전이라 저장소에 포함하지 않습니다.
- 코드·집계 결과만 공개/공유 대상입니다.
