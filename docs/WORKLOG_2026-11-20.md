## 3. 확정 사항 (ChatGPT 교차검토 + 자체 실측)

- **데이터**: ON/OFF 균형쌍 108쌍(거리3×조도3×시점4×3), 실제 사람 검수 400대, 실제 프레임 360장(12카메라), 상태판정 628쌍 유지
- **모델**: 검출 **YOLO26n 1클래스(960px)**, 상태 **YOLOv8n-cls(160px)**, RT-DETR·SAM2·램프 서브헤드·DINO LoRA는 이번 일정 제외
- **기능**: EWMA α0.45, 진입 0.80/해제 0.40, 최소 3회, 카메라별 트랙 분리·만료, UNKNOWN(폭 40px 미만), temperature scaling, 도로 ROI·자막 마스크, 감사 로그
- **지연 예산**: 55ms(입력5+검출25+분류16+트랙4+로그5), 합격 평균 ≤50ms / p90 ≤60ms
- **평가**: 실제 소등 재현율 ≥0.70(라벨 확보 시), 오경보 ≤1건/카메라·시간, 중복 알림 0, 알림 지연 p95 ≤2초, ECE ≤0.08
- **표기 규칙**: 모든 지표에 REAL-ITS / PUBLIC-PAIRED / SYN-ROI 표기, 실제 OFF 없으면 N/A(n=0)
