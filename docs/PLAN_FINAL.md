# 최종 계획 (확정) — 2026-11-20 결정

기준일 2026-11-20 / 최종보고 2026-12-18 / RTX 3080 12GB / GPU 총 180분
이 문서는 ChatGPT(DevSpace MCP1) 교차검토 3라운드와 자체 실측을 반영해 **결정을 고정**한 것이다.

### 조건 행렬 (필수)
- **거리 3** (근 80px↑ / 중 40~79px / 원 18~39px) × **조도 3** (저·중·고) × **시점 4** (정면·후면·사선 2종) = **36조건 × 3대 = 108쌍**
- 시점은 실제 CCTV 진행방향과 물리적으로 일치해야 하고, 조건마다 서로 다른 원본 프레임을 우선 사용
- 기상·차체 색상은 조건에 고정하지 않고 균형 배분

## 3. 기능 및 지연 예산 (확정)

| 기능 | 결정 | 근거/비고 |
|---|---|---|
| 트랙 판정 | EWMA α=0.45, **진입 0.80 / 해제 0.40**, 유효 관측 최소 3회 | 연속 프레임 상관성 때문에 무제한 로그우도 누적 금지 |
| 트랙 관리 | **카메라별 독립 ID**, 2회 누락 시 종료, 트랙당 최초 알림 1회 | 카메라 간 객체 혼동·반복 알림 방지 |
| UNKNOWN | 폭 **40px 미만**, 램프 판독 불가, 높은 불확실성 → 보류 | 18~39px는 별도 탐색 지표로 평가 |
| 캘리브레이션 | Temperature scaling(검증셋만) | ECE/NLL 개선 없으면 T=1 유지 |
| 도로 ROI 마스크 | 카메라별 도로 polygon + 자막·표지판 exclusion mask(수동 우선) | 36프레임에서 자막 그림자 오탐 발생 |
| 감사 로그 | BBOX·상태·신뢰도·트랙 ID·UNKNOWN 사유·판정 시각 | 오탐 원인 추적 |
| SAM2·램프 서브헤드 | **최종 파이프라인 제외** | 2~4px 램프 + 180분 예산 |

### 지연 예산 (목표 55ms)
| 단계 | 예산 |
|---|---|
| 입력·전처리 | 5ms |
| YOLO26n 검출(960px) | 25ms |
| 차량 크롭 배치 분류(160px) | 16ms |
| 트래킹·판정 | 4ms |
| 로깅·오버레이 | 5ms |

**합격 기준: 평균 ≤ 50ms, p90 ≤ 60ms.** 이미지 저장·네트워크 전송은 별도 측정.

### 1주차 필수 코드 수정 (DevSpace 점검 지적)
1. `app/models.py`: `trained=True`에서 모델명과 무관하게 기존 가중치를 로드 → **실제 로드 경로·모델명을 로그에 기록**
2. `app/judge.py`·`app/its_watch.py`: 카메라별 트랙 분리·만료 없음 → 다른 카메라 정지 프레임이 동일 트랙으로 연결될 수 있음
3. 위 수정 전까지 **기존 36프레임 이벤트 결과는 트랙 성능 증거로 사용하지 않는다**(오탐 1건 사실만 기록)

## 4. 평가 (확정)

### 분할
| 구분 | 카메라 | 프레임 | 수동 검수 차량 |
|---|---|---|---|
| Train | 6대 | 180 | 200대 |
| Validation | 3대 | 90 | 80대 |
| Test | 3대 | 90 | 120대 |
| 합계 | 12대 | 360 | 400대 |

- 카메라 간 완전 분리, 동일 클립·파생 이미지 중복 금지. 기존 51프레임은 해당 카메라 분할에만 편입
- 트랙 평가용 **연속 영상 4카메라·시간** 목표(최소 2카메라·시간)

### 지표와 성공 기준
| 지표 | 기준 | 적용 데이터 |
|---|---|---|
| 차량 mAP50 | ≥ 0.65 | REAL-ITS 수동 BBOX |
| 차량 Recall | ≥ 0.75 | REAL-ITS |
| 상태 F1 | ≥ 0.80 | PUBLIC-PAIRED 원본 그룹 분리 |
| 상태 F1(JPEG35) | ≥ 0.75 | 동일 크롭 열화 |
| 실제 소등 Recall | ≥ 0.70 (OFF 확보 시에만) | REAL-ITS |
| 합성 이벤트 Recall / Precision | ≥ 0.70 / ≥ 0.60 | SYN-ROI 독립 영상 |
| UNKNOWN 후 커버리지 | ≥ 70% | ON/OFF/UNKNOWN 검수셋 |
| 오경보 | ≤ 1건/카메라·시간 | REAL-ITS 연속 영상 |
| 동일 트랙 중복 알림 | 0건 | 연속 영상 |
| 알림 지연 p95 | ≤ 2초 (5fps) | 연속 이벤트 |
| ECE | ≤ 0.08 | 독립 상태분류 평가셋 |
| 처리 지연 p90 | ≤ 60ms | 단일 카메라 |

**표기 규칙**: 모든 지표에 `REAL-ITS` / `PUBLIC-PAIRED` / `SYN-ROI` 중 하나를 붙인다. 실제 OFF 정답이 없으면 `N/A (n=0)`으로 기록하고 합성 성능으로 대체하지 않는다.
