# 모델 설계 (Model Design)

## 1. 문제 특성
- 야간 CCTV, 차량 폭 중앙값 **50px**(18~110px) → 소형 객체 검출
- 소등 차량은 등화가 없어 밝기·대비 단서가 약하고, 정상 차량과의 차이는 주로 램프 광원 유무
- 실제 소등 라벨이 거의 없음(현재 0) → **합성으로 검출기를 만들고, 상태 판정은 실제 대응쌍으로 학습**하는 분리가 필요
- 일반 차량도 함께 인식해야 함(운영 화면에서 정상/소등을 같이 표시)

## 2. 구조 후보 비교
| 구조 | 장점 | 단점(우리 실측) |
|---|---|---|
| A. 단일 2클래스 검출 | 단순, 1회 추론 | 실제 프레임에서 stealth 출력 0(소등 라벨 부재). 합성 삽입 흔적에 과적합 |
| B. 검출 + 상태 판정(2단계) | 검출은 실제 프레임으로, 상태는 실제 대응쌍으로 학습 | 추론 2회(지연 증가) |
| C. 3클래스(on/off/unknown) | 불확실성 표현 | unknown 라벨 확보 비용 큼 |

**선택: B(2단계)** — 검출기와 상태 판정기를 분리합니다.

## 3. 최종 구조

```
프레임(960px) ─▶ Stage-1 검출기(YOLOv8n, 2클래스: normal_vehicle / stealth_vehicle)
                      │  차량 BBOX + 클래스 확률
                      ▼
                 크롭(차량 영역, 패딩 8%)
                      │
                      ▼
             Stage-2 램프 상태 분류기(YOLOv8n-cls, 160px, on/off)
                      │  p_off
                      ▼
        판정 규칙: stealth 후보 = (Stage-1 stealth 확률 ≥ τ1) OR (p_off ≥ τ2)
                  최종 알림은 연속 N프레임 이상 지속 시(깜빡임 억제)
```

### Stage-1 (검출)
- 데이터: ROI 편집 합성본 144장(stealth 1대) + 실제 프레임 51장(normal) + 합성 주변 차량(normal)
- 학습: YOLOv8n, imgsz 640, 100 epoch, batch 8, amp off, patience 25
- 목적: 차량 위치 + 소등 후보 1차 스크리닝

### Stage-2 (상태 판정)
- 데이터: 실제 ON/OFF 대응쌍 628쌍 + 합성 stealth 크롭
- 학습: YOLOv8n-cls, imgsz 160, 30 epoch
- 목적: 소등 여부의 정밀 판정(합성 아티팩트 영향 제거)

### 판정 규칙
- τ1 = 검증에서 F1 최대가 되는 값(초기 0.25), τ2 = 검증에서 재현율 0.7 이상·FP/frame ≤ 1.0이 되는 최소값
- 연속 3프레임 이상 유지 시 알림(단일 프레임 오탐 억제)

## 4. 왜 단일 구조를 쓰지 않는가(실측)
- 단일 2클래스 검출기 4회 실험 모두 실제 프레임에서 stealth 0건 → 소등 판별을 검출기 안에서 학습할 데이터가 없음
- 상태 판정을 실제 대응쌍으로 학습한 분류기는 **재현율 87.8%**(정상 100%)를 달성
- 즉 "무엇이 차량인가"는 합성+실제 프레임으로, "램프가 꺼졌는가"는 실제 대응쌍으로 나누는 것이 데이터 현실에 맞습니다

## 5. 실제 ITS 적용 설계
- 입력: 기존 CCTV RTSP/스냅샷에서 **1fps 샘플링**(연속 프레임 알림 억제와 동일 근거)
- 처리: 프레임당 960px 추론 → 차량 크롭 분류. 목표 지연 ≤ 50ms/프레임(GPU), 배치 8로 묶어 처리
- 배포: 카메라별 ROI 마스크(도로 영역만), 알림은 이벤트 단위(차량 ID는 프레임 간 단순 IoU 추적)
- 개인정보: 원본 영상 미저장, 알림 시 크롭만 일시 보관(예: 10분), 번호판 마스킹 옵션
- 온프레미스 우선(경찰/지자체 망), 모델 파일은 ONNX 변환 후 TensorRT/OpenVINO 선택

## 6. 평가 연결
- 판정 기준은 `docs/EVALUATION_PLAN.md`(파일럿 재현율 0.50 / 최종 0.70, FP/frame ≤ 1.0, 지연 ≤ 50ms)을 그대로 사용
- Stage-1·Stage-2 각각의 지표와, 합친 파이프라인 지표를 모두 기록

## 9. 실시간 열화 대응 (측정)
- 테스트 15프레임 clean 대비 차량 검출 유지율: 블러 0.81 / 흔들림 0.95 / JPEG q35 0.81 / 야간 노이즈 1.14
- 지연: clean 11.9ms, 열화 12.7~16.3ms (p90 20.1ms 이하), 기준 50ms 이내
- 대응: 모션블러/저화질/노이즈 증강 추가, 1fps 샘플링 + 3프레임 지속 알림
