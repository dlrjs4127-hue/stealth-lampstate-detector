# 야간 CCTV 스텔스(램프 소등) 차량 검출 연구

야간 CCTV 영상에서 **전조등·후미등을 끄고 주행하는 차량(스텔스 차량)** 을 찾는 검출기 연구입니다.
독립심화학습2(경희대 산업경영공학부, 2026-2학기) 과제로 진행했고, 실험 코드·결과·실험일지를 기록합니다.

## 문제 정의
- 야간 CCTV는 조명이 없으면 차량이 어두운 덩어리로만 보여, 사람도 소등 차량을 놓치기 쉽습니다.
- 목표: 실제 도로 CCTV 프레임에서 소등 차량 후보를 자동으로 표시하는 모델.

## 접근 방법
1. **합성 데이터 구축** — 실제 ITS 야간 프레임 위에 생성 모델(ChatGPT 이미지 생성)로 만든 차량을 얹어, 실제 카메라의 노이즈·조명·압축 특성을 그대로 유지한 학습 데이터를 만듭니다.
2. **자동 라벨링 + 검수** — 차량 후보를 검출한 뒤 램프 점등 여부로 클래스를 나누고, BBOX 프리뷰로 눈으로 확인합니다.
3. **조도·노출·색온도 변형** — 같은 장면을 base / dark / gamma_low / cool / warm / noisy / blur 7종으로 파생해 조명 조건 변화에 대응합니다.
4. **2클래스 검출 학습** — normal_vehicle / stealth_vehicle을 YOLOv8n으로 학습합니다.
5. **홀드아웃 실제 프레임 평가** — 학습에 쓰지 않은 실제 프레임에서 검출 수와 화면을 확인합니다.

## 실험 결과

| 실험 | 데이터 구성 | 검증 | 실제 프레임 적용 |
|---|---|---|---|
| A 완전 생성 장면 | 생성 도로 59장 (정상 766 / 스텔스 171) | mAP50 0.782 | 정상 366 · 스텔스 202 |
| B ITS 합성 1클래스 | 합성 58장 + 실프레임 음성 45장 | mAP50 0.995 | 스텔스 0 |
| C ITS 합성 2클래스 | 합성 58 + 실프레임 51(정상 라벨) | mAP50 0.961 / P 0.904 | 정상 131 · 스텔스 0 |
| D 조도 변형 + 실제 OFF 혼합 | 합성 변형 406 + 실제 OFF 크롭 628 + 실프레임 51 | results/metrics_exp3.json | results/metrics_exp3.json |
| E 혼합 분류기 | 생성 + 실제 ON/OFF 대응쌍 | 소등 재현율 87.8% | 후보 7/310 (2.3%) |

- A는 도로 전체를 생성한 데이터라 실제 카메라 특성이 달라, 실제 프레임에서 소등 판별이 되지 않았습니다.
- B·C는 실제 프레임을 배경으로 써서 배경·조명이 실제와 같아졌고, 합성 표적은 정확히 학습됐습니다.
- E처럼 실제 ON/OFF 대응쌍을 섞으면 소등 판별 신호가 살아납니다(재현율 87.8%).

## 재현 방법
```bash
pip install ultralytics opencv-python numpy
python src/build_dataset_from_generated_scenes.py     # 생성 장면 → 2클래스 데이터셋
python src/train_detector_its_composite.py            # ITS 합성본 학습 + 실제 프레임 평가
python src/train_detector_lighting_variants.py         # 조도 변형 + 실제 OFF 혼합 학습
python src/eval_on_its_frames.py                       # 실제 프레임 추론·시각화
```
